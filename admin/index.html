Как опубликовать изменения
  1. Нажми «Проверить и скопировать».
  2. Открой GitHub Actions и выбери workflow Portfolio CMS.
  3. Выбери тот же файл, вставь скопированный JSON в поле content и запусти workflow.
  4. Открой созданный Pull Request, проверь изменения и объедини его в main.

Workflow принимает запуск только от аккаунта Cr1staloriginal. Данные сначала попадают в отдельную ветку и PR — напрямую в main CMS не записывает.

Админ-панель не является приватным хранилищем: редактируемые JSON-файлы публичны. Не помещай сюда пароли, токены, личные данные или закрытую информацию.

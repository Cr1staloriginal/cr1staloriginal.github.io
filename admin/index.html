Управление портфолио

CMS работает без VPS и отдельного backend. Данные публикуются через GitHub Actions и Pull Request.

GitHub

Для запуска CMS нужен доступ к репозиторию.

РЕЖИМGitHub Actions

После проверки JSON будет скопирован. В открывшемся GitHub Actions выбери файл, вставь содержимое в поле content и нажми Run workflow. Запуск разрешён только аккаунту Cr1staloriginal. Workflow создаст Pull Request; сайт обновится после его проверки и слияния с main.

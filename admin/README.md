# Управление содержимым портфолио

## Админ-панель

Интерфейс находится по адресу /admin/. Он активируется после развёртывания backend из каталога backend/ и настройки API URL в portfolio-api meta tag в admin/index.html (и в index.html, если API находится на отдельном origin).

Вход выполняется через GitHub. Разрешён только аккаунт, указанный в ADMIN_GITHUB_LOGIN. Секреты GitHub App остаются на сервере.

## Доступные данные

- data/site-data.json — публичный статус и активные направления.
- data/changelog.json — история обновлений.
- data/achievements.json — достижения и подтверждённые этапы.

После сохранения backend создаёт отдельную ветку и Pull Request. Изменения не попадают на сайт до проверки и слияния PR с main.

## Безопасность

GitHub Pages сам по себе не может безопасно хранить токены, аутентифицировать администратора или доставлять сообщения. Не добавляйте секреты в HTML, CSS, JavaScript или JSON. Используйте только серверные переменные окружения и HTTPS.

Технические инструкции по запуску: ../backend/README.md.

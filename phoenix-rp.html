Phoenix RP

Нативное Android-приложение для создания персонажей и независимых RP-историй с локальным хранением данных и направлением на офлайн-диалоги с AI-моделями.

01 / IDEA

Идея

Сделать мобильное пространство для нескольких параллельных ролевых историй, редактируемых персонажей и локальных данных, с возможностью в перспективе запускать языковые модели непосредственно на устройстве.

Приоритет — самостоятельность историй, сохранение переписок и контроль пользователя над персонажами и импортируемым содержимым.

02 / IMPLEMENTED

Что уже реализовано

  • Независимые RP-истории с отдельным хранением персонажей.
  • Редактор личности, внешности, биографии, стиля речи и стартовой сцены.
  • Импорт персонажей из JSON-текста и экспорт JSON-файлов.
  • Локальная память в виде заметок, привязанных к истории.
  • Импорт GGUF-файлов во внутреннее хранилище и каталог моделей.
  • Импорт статей Fandom через MediaWiki API с ручным запасным вариантом.
  • Светлая и тёмная темы, адаптация под вырезы и широкие экраны.
03 / CURRENT LIMITATIONS

Что пока не готово

llama.cpp

Нативный движок ещё не включён в приложение; текущая реализация задаёт границу интеграции.

Запуск GGUF

Файлы можно импортировать и каталогизировать, но локальный инференс пока недоступен.

Память диалога

Заметки хранятся локально, но пока не извлекаются автоматически и не добавляются в prompt модели.

JSON file import

Импорт JSON через вставку текста работает; импорт через системный выбор файла остаётся будущей задачей.

AI-ответы

Вместо полноценной языковой модели в текущем чате используется демонстрационный ReplyComposer.

Совместимость Fandom

Поддерживаются стандартные HTTPS-страницы *.fandom.com; некоторые нестандартные wiki могут потребовать ручной вставки текста.

04 / STACK

Архитектура

  • Kotlin — основной язык Android-клиента.
  • Jetpack Compose — интерфейс.
  • Room — локальная база данных.
  • ViewModel — состояние экранов.
  • GitHub Actions — облачная сборка Android.
  • Python bot — отдельный экспериментальный компонент репозитория.
05 / BUILD

Сборка

Android-проект собирается через GitHub Actions. Подпись релизов требует отдельно настроенных GitHub Actions Secrets. Keystore и пароли нельзя добавлять в репозиторий.

Описание отражает текущее состояние README проекта и не выдаёт запланированные функции за готовые.

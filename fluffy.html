01 / OVERVIEW

О проекте

Fluffy задуман как универсальный бот для Discord-сообществ: вместо набора отдельных ботов он собирает основные функции в одном месте. В репозитории есть модульная загрузка расширений, инициализация базы данных, конфигурация через переменные окружения и проверки Python-кода через GitHub Actions.

03 / UNDER THE HOOD

Техническая сторона

Py

Python + disnake

InteractionBot и slash-команды Discord; функции организуются в расширения/cogs.

DB

SQLite

Локальная база данных для хранения данных приложения и настроек.

ENV

Конфигурация

Секреты и параметры задаются переменными окружения; токен не должен попадать в репозиторий.

CI

Проверки кода

GitHub Actions запускает компиляцию Python и импорт модулей при push и pull request.

PROJECT STRUCTURE / CONCEPT
Fluffy/
├── main.py          # запуск и загрузка расширений
├── database.py      # инициализация БД
├── cogs/            # функциональные модули
├── utils/           # общие утилиты и логирование
├── .env             # локальные секреты (не коммитить)
└── README.md        # описание и запуск

Схема показывает основные элементы проекта, а не гарантирует полный актуальный список файлов репозитория.

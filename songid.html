CASE STUDY / EXPERIMENT
ЭКСПЕРИМЕНТАЛЬНЫЙ ПРОТОТИП

SongID

Небольшой веб-эксперимент с интерфейсом загрузки и поиска аудиотреков и идеей классификации музыкальных жанров. Это прототип для исследования подхода, а не готовый музыкальный сервис.

HTMLCSSJavaScriptWeb Audio API
Открыть репозиторий ↗
01 / PURPOSE

Зачем создан

Проверить идею интерфейса вокруг аудиофайлов и поэкспериментировать с браузерными возможностями обработки звука. Проект полезен как небольшая площадка для прототипирования и проверки UX-идей.

02 / SCOPE

Границы прототипа

Репозиторий содержит клиентскую страницу, стили и JavaScript. Наличие интерфейса загрузки или концепции распознавания не означает, что существует полноценный backend-каталог, надёжная идентификация треков или production-классификатор.

03 / STACK

Технологии и дальнейшие шаги

HTML и CSS

Структура и визуальное оформление веб-прототипа.

JavaScript

Клиентская логика и взаимодействие с интерфейсом.

Web Audio API

Браузерная аудио-платформа для экспериментов со звуком.

Возможное развитие

Уточнить сценарии, провести тестирование и отдельно спроектировать серверную часть, если идея будет продолжена.
